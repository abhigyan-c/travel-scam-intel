What to include

Describe the problem, when it happened, the requested location, and any request ID or report receipt. Include a source link when requesting a factual correction. Remove unrelated personal information from screenshots.

Reports and privacy requests

Reports are anonymous. A receipt helps locate a submission, but does not verify the alleged incident or establish ownership. Explain which content you want reviewed or removed; do not provide extra sensitive data to prove identity. Requests require manual assessment. Hiding a finding does not automatically erase source records or backups. See the privacy policy for the current retention limits.

Responsible disclosure

Describe a suspected security issue privately without exploiting it, extracting other users’ data, or posting credentials publicly. Include reproducible steps using synthetic data where possible.
