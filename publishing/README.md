# Public submission draft

`travel-scam-intelligence/` contains portable metadata for the existing MCP server.
It is not a submitted or approved listing and is not yet a complete submission ZIP.
Follow [publishing readiness](../docs/publishing-readiness.md) for exact missing
URL/demo/verification and host-acceptance gates. All eight drafted review cases are
**Not run against this candidate**. No secrets or private app bindings belong here.

The generated icon is an opaque 1254×1254 PNG (1,235,580 bytes), suitable for both
listing and composer size requirements. Its teal pin and amber compass silhouette
was visually inspected; the navy background provides contrast on light/dark host
surfaces. It has no text or guarantee-of-safety symbol. No separate dark-mode asset
is supplied. The creator can replace the icon before submission.

Generated with the built-in image-generation tool, using this prompt:

> Create a polished square app icon for Travel Scam Intelligence, an evidence-backed
> travel research app. One distinctive stylized teal map pin combined with a small
> warm amber compass needle on a solid deep navy background. Minimal bold geometric
> silhouette, flat restrained vector-like finish, generous padding, clear at 48
> pixels. No text, no letters, no shield/checkmark or claim of guaranteed safety,
> no gradients, no photorealism, no tiny map details. Single 1024x1024 square icon,
> opaque background.

The returned artifact's actual dimensions are recorded above; the request size
is not treated as the measured size. It is stored in the project at
`travel-scam-intelligence/assets/icon.png`, not only in a local generation cache.
